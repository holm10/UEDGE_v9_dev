## Deviations from the plan
- workh bound (02e6e60): Forthon --omp ProcessDim/GetSize take S.split('(')[1].split(')')[0], so the nested '(' in
  2*kxords_aph*(nxdata_aph+1) produced uncompilable copy routines (AIUE-71). Rewritten as the equal
  2*kxords_aph*nxdata_aph+2*kxords_aph. Consequence (I1-m2 ii): the generated serial aph_p.F90 and aphpymodule.c differ from the
  base in the text of this bound only; the size is arithmetically equal.
- Defaults gate (I1-m2 i): the plan's pair (AIUE-56 builds) gives RESULT: INCOMPLETE on tool policy (base not on
  origin/v9-develop) although every comparison agrees. The certified complete gate is run against base-serial/base-omp (0fac655):
  0fac655 is an ancestor of origin/v9-develop and of 1553e75, and the only product diff 0fac655..1553e75 is AIUE-56's
  OMPJacBuilder copy order, which runs neither in serial nor with both OpenMP switches 0.
- TSan launch: cli.py run under DYLD_INSERT_LIBRARIES segfaults at start-up; the harness worker is started directly in a run
  directory prepared with prepare_rundir (AIUE-60-tsan-prep.py), OMP_STACKSIZE=64M. Every run wrote its record, then exited 134
  at interpreter shutdown.
- Untested at run time (I1-m1): B2 (sputflxllim/rlim, limiter sputtering) and B4 (workh, istabon=5/6) were never executed in
  a threaded run (no preset enables them; the istabon=5/6 nwfits data isn't on this machine). Covered by Probe S, the build,
  the generated per-thread allocation (same copyin(pcopy__) as the exercised bbb arrays) and B2VAhL's write-before-read.
- Behaviour notes for the PR: com timers are shared and atomic, so under OpenMP they sum thread-seconds over threads;
  aph.iflag_aph is no longer updated by rqa/rra/rsa (only by the aphread setup calls).
